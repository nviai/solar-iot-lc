Callback address

For the Callback Address field of your developer-portal application.

{{ icon('info') }}

SolaX pushes to this endpoint for the Data Subscription feature (realtime or alarm data) and for asynchronous remote-control results.

  1. It must be reachable from the internet — during development use a tunnel such as ngrok http 8000 and append /callback/solax.
  2. It must answer 2xx quickly, or the delivery is retried.
  3. Set CALLBACK_SECRET to require a shared secret in the X-Solax-Signature / X-Callback-Secret header or ?secret=.

The envelope is not published, so any JSON shape is accepted, logged below, and ingested when it looks like telemetry.
