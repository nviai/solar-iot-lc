Adding a device

  1. Pair the switch in the Smart Life / Tuya app, then run python -m tinytuya wizard on the same LAN. It writes devices.json (id and local key) and snapshot.json (IP and protocol version).
  2. Add an entry to {{ settings.devices_file.name }} — the shape is in devices.example.json: 
    {
  "devices": [
    {
      "id": "ev-charger",
      "name": "EV charger",
      "kind": "tuya_switch",
      "tuya": { "device_id": "…", "ip": "192.168.1.50",
                "local_key": "…", "version": 3.4, "dp": 1 }
    }
  ]
}
  3. Give the switch a fixed IP in your router (DHCP reservation), then restart this service.
